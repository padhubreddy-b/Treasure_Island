# 🏝️ Treasure Island

A simple text-based adventure game built using Python. The player makes a series of choices to find the hidden treasure. Every decision affects the outcome of the game.

## Features

- Interactive command-line gameplay
- Multiple decision paths
- Win and Game Over scenarios
- Uses nested `if`, `elif`, and `else` statements

## How to Run

```bash
python Treasure_Island.py
```

## Gameplay

- Choose **left** or **right**.
- Decide whether to **wait** or **swim**.
- Select one of the three doors:
  - 🔴 Red
  - 🟡 Yellow
  - 🔵 Blue

Choose wisely to find the treasure!
